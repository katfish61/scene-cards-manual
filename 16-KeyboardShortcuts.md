# Chapter 16 — Keyboard Shortcuts

All custom keyboard shortcuts are 🍎 macOS only. Scene Cards has no
custom shortcuts on 📐 iPadOS — use the navigation bar buttons and
⋯ overflow menu (§15.2) instead.

---

## Modes

| Shortcut | Action |
|---|---|
| `⌘⇧1` | Switch to Scenes mode |
| `⌘⇧2` | Switch to Locations mode |
| `⌘⇧3` | Switch to Schedule mode |

## Project menu

| Shortcut | Action |
|---|---|
| `⌘⇧N` | New Project |
| `⌘⇧O` | Open Project… |

## File

| Shortcut | Action |
|---|---|
| `⌘S` | Save |
| `⌘⇧S` | Save As… |
| `⌘P` | Print Wall Layout… |

## Import

| Shortcut | Action |
|---|---|
| `⌘⇧I` | Import Script PDF or FDX… |
| `⌘⌥I` | Batch Import Images (Folder)… |
| `⌘⌥⇧I` | Batch Import Images (Select Files)… |
| `⌘⌃I` | Import Project Data… |

## Edit

| Shortcut | Action |
|---|---|
| `⌘Z` | Undo |
| `⌘⇧Z` | Redo |
| `⌘X` | Cut |
| `⌘C` | Copy |
| `⌘V` | Paste |
| `⌘A` | Select All |

## Cards

| Shortcut | Action | Notes |
|---|---|---|
| `⌘⌥N` | Insert Card After | Requires a card to be selected |
| `⌘⌥O` | Toggle OMITTED | Requires a card to be selected |
| `⌘⌥R` | Renumber From Here | Requires a card to be selected |

## Help

| Shortcut | Action |
|---|---|
| `⌘/` | Keyboard Shortcuts… |
| `⌘⇧?` | Quick Start… |

## Dialogs

These work inside drawing and text-note panels:

| Shortcut | Action |
|---|---|
| `⌘↩` | Save / confirm |
| `⎋` | Cancel / close |
| `⌘Z` | Undo (drawing panel) |

---

> ✱ **Tip** — all import shortcuts share the `I` key with different
> modifier combinations. A quick way to remember them: `⌘⇧I` for
> script (the most common import), `⌘⌥I` for images, `⌘⌃I` for
> session data.
